Buka Formulir Pendaftaran

Pertanyaan umum

Apakah data saya aman?

Pada prototype ini data hanya tersimpan di browser perangkat Anda. Untuk layanan nyata, data calon jamaah memerlukan server aman dengan kontrol akses.

Apakah pengisian formulir berarti sudah mendaftar haji resmi?

Tidak. Formulir Haji Yuk hanya permintaan pendaftaran awal untuk ditindaklanjuti petugas. Pendaftaran haji resmi dilakukan melalui kanal resmi pemerintah.

Mengapa harga paket disebut simulasi?

Seluruh harga, jadwal, dan fasilitas pada prototype belum diverifikasi sehingga ditandai sebagai simulasi. Konfirmasikan kepada petugas sebelum memutuskan.

Bagaimana cara petugas mengelola data?

Petugas masuk melalui tautan Area Admin di bagian footer untuk memeriksa permintaan, memperbarui status, dan mengelola paket serta panduan.
