    Penyimpanan data

    Data disimpan di localStorage browser perangkat ini, meliputi paket, permintaan pendaftaran, panduan, pengumuman, dan log aktivitas. Sesi login admin disimpan di sessionStorage.

    Data tidak tersinkronisasi ke perangkat lain. Membersihkan data browser akan menghapus seluruh data prototype.

    Sesi & akses

    Anda sedang masuk sebagai Admin Haji Yuk. Logout akan mengakhiri sesi dan mengembalikan Anda ke halaman login admin.
